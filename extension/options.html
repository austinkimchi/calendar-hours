Calendar Hours

Choose how event durations appear in Google Calendar.

Format

Use {value} for the number and {unit} for the unit. Example: ({value} {unit}).

Example: SCU Block (3.17 hours)

Ways to add hours

Type the keyword in a title and it is replaced with calculated hours.

Separate matches with commas. Matching uses whole words or phrases, ignoring case. For only your SCU blocks, enter SCU Block.

When enabled, the extension opens the changed event, corrects its title, and saves it automatically. It also updates titles when you edit start or end times in the event editor. Existing suffix replacement is enabled with this setting. Events with repeat rules are left for you to review.
