# Calendar Hours privacy policy

Effective October 26, 2026

Calendar Hours reads the title, start time, end time, and date fields of the Google Calendar event that you are editing. It uses those fields locally in your browser to calculate an elapsed duration and propose or insert text in the event title. It does not access events outside the open Calendar page, use the Google Calendar API, or save an event for you.

Calendar Hours does not collect, transmit, sell, or share calendar event data. It has no analytics, advertising, account system, server, or network requests. Your formatting and trigger preferences are stored using the browser's extension storage. If browser sync is enabled, the browser provider may sync those preferences under your browser account. No event titles or event times are stored there.

The extension requests access to `calendar.google.com/calendar/*` because that is where the event editor appears. It requests the `storage` permission solely for preferences. You can remove the extension and its stored preferences in your browser's Extensions settings.

For questions about this policy, use the support contact listed on the Chrome Web Store listing.
